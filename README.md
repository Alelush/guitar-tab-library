# Guitar Tab Library

Веб-приложение для хранения и работы с гитарными табулатурами.

Пользователи могут создавать аккаунты, добавлять табулатуры, сохранять их в избранное, а также получать доступ к платным материалам через систему покупок.

## Возможности

- Регистрация и авторизация пользователей
- Аутентификация с использованием JWT
- Хеширование паролей с помощью bcryptjs
- Разграничение прав пользователей:
  - User
  - Creator
- Добавление и редактирование табулатур
- Публичные и приватные табулатуры
- Добавление табулатур в избранное
- Поиск и просмотр табулатур
- Система покупок платных табулатур
- Хранение информации о транзакциях
